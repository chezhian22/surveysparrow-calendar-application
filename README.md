# 📆 Calendar and Timeline Web Application

A modern, responsive web application built with **React** that displays a calendar with event management, a mini-sidebar calendar, and a day-wise timeline view. Users can view, explore, and manage events interactively on a daily or monthly basis.

---

## 🚀 Features

- 🗓️ **Monthly Calendar Grid** – Navigate and view events per day.
- 🕒 **Day Timeline View** – Detailed hour-by-hour breakdown of events.
- ⭐ **Important Task Highlighting** – Starred or priority events shown in a separate section.
- 📅 **Sidebar with Mini Calendar** – Persistent monthly view with today highlighting.
- 📱 **Fully Responsive UI** – Optimized for desktop and mobile devices.
- ⚙️ **React Router v6+** – Client-side routing for calendar and day views.
- 🔄 **Dynamic State Management** – Controlled with React `useState` and `useEffect`.

---

## 🧑‍💻 Tech Stack

React – Used as the main frontend library for building the UI components.

React Router – Enables client-side routing between calendar and timeline views.

dayjs – A lightweight JavaScript library for date and time manipulation.

CSS – Custom CSS used for styling and making the application responsive.

React Icons – Provides icon support with minimal bundle size.

JSON – Used to store and simulate static event data for rendering in the app.
